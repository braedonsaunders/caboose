# Coverage gaps closed after the survey of main, 2026-11-04

Re-checked with `survey.py --only` on the agent seat.

| Application | Before | After | Fix |
|---|---|---|---|
| Freeplane (Flatpak, Java) | no window | window, picture and OCR | The launcher no longer gives a Flatpak's JRE the host's ATK wrapper, which its sandbox cannot load (AWT failed to start). The Flatpak runtime has no ATK bridge of its own, so there is no tree. |
| qBittorrent (Flatpak, Qt 6) | no window | window, tree | A killed qBittorrent leaves a single-instance lock that, inside a sandbox where its pid is always 2, stops the next start. The survey and the benchmark now close windows (xdg_toplevel.close through the seat) before they signal. |
| ImageMagick `display` (X11) | process unknown | process known, picture and OCR | An X11 window without `_NET_WM_PID` gets its process from the X server (X-Resource). Xlib draws no accessibility tree. |
| GNOME GTK 4 theme switcher | no window | removed | Left by the WhiteSur theme installer; it needs GTK 4 Python bindings the image does not have. The image builds remove it. |
| Xfce Display | no window | hidden | The phone sets the display's size, so the image hides the entry (the compositor offers no output management; agreed with its owner). |
| Xfce Keyboard, Mouse, Accessibility | no window | windows, trees | The launcher starts a program again on X11 when it quits saying it needs X11. |
